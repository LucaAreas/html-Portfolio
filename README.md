# Samyuktha — Web Developer Portfolio (improved)

Este repositório contém uma versão melhorada de um portfólio pessoal estático em HTML/CSS/JS. O objetivo aqui é transformar um projeto de estudo em um site com aparência mais profissional, com foco em semântica, acessibilidade, responsividade e pequenas interações JavaScript.

Principais melhorias
- Estrutura HTML semântica e melhor uso de headings
- Responsividade com media queries e layout em grid
- Variáveis CSS para tipografia e paleta de cores
- Tema claro/escuro persistente (localStorage)
- Contador de visitas e favoritos (localStorage)
- Pesquisa de projetos, toasts e modal para visualização de projetos
- Acessibilidade: atributos alt, foco em modais, atalhos de teclado
- Loading screen e pequenas animações

Como usar
1. Abra o arquivo index.html em um navegador moderno para testar localmente.
2. Para desenvolvimento, você pode servir a pasta com um servidor estático (ex.: live-server, http-server ou a extensão Live Server do VS Code).
